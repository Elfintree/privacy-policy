Збір даних

Додаток не збирає, не зберігає і не передає жодних персональних даних користувача.

Дозволи

Додаток не запитує доступу до геолокації, контактів, камери або інших персональних даних. Місто обирається вручну зі списку.

Зовнішні сервіси

Додаток використовує відкриті API для отримання даних про погоду:

  • Open-Meteo (open-meteo.com) — погодні дані
  • NOAA — геомагнітні дані (Kp-індекс)

Ці сервіси не отримують жодних персональних даних користувача.
